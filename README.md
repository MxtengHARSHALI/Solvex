# Solvex
A smart automated solar panel cleaning robot that uses a rack-and-pinion mechanism, rotating roller brush, water spraying system, and wiper to remove dust and dirt from solar panels. Controlled by Arduino and IR sensors, the system aims to reduce manual effort, save cleaning time, and maintain the efficiency of solar panels.
# Problem Statement
- Dust accumulation reduces solar panel efficiency.
- Manual cleaning requires time and effort.
- Regular maintenance can be difficult for large solar installations.
